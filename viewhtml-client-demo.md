# Single-file HTML demos for client review without deploying

Clients rarely want a git clone or a staging URL for a five-minute layout question. A single HTML file with a live preview link is often enough.

Open [ViewHTML](https://viewhtml.app), paste the file contents (HTML/CSS/JS), confirm the render, and send the share link. They can open it on phone or desktop without accounts.

## Good fits
- Hero / pricing section mockups from an AI coding session.
- Form layout checks before wiring a backend.
- Teaching or pairing notes where a build step would get in the way.

Keep demos small and self-contained. When the prototype grows into a real app, move it to proper hosting — until then, [viewhtml.app](https://viewhtml.app) keeps the feedback loop short.
